# Contributing

Thank you for contributing to TrustTrade.

1. Open an issue describing the proposed bug fix or research extension.
2. Create a focused branch and keep generated outputs, credentials and private
   datasets out of commits.
3. Run `bash scripts/validate_release.sh` before submitting a pull request.
4. Document changes that affect prompts, data cutoffs, model versions, trading
   costs or reported metrics.
5. Add an offline test for new deterministic behavior whenever practical.

Contributions inherited from or submitted upstream to TradingAgents remain
subject to its Apache-2.0 license and contribution terms. By submitting a
contribution here, you agree that it may be distributed under Apache-2.0.
