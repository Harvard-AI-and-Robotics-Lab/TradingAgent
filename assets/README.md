# README assets

- `trusttrade_framework.png` is the Figure 3a framework image downloaded from
  the TrustTrade arXiv HTML release:
  <https://arxiv.org/html/2603.22567v1/trusttrade.png>.
- `risk_return_tradeoff_2024q1.png` is generated by
  `tools/plot_rule_baselines/main_v2.py` and corresponds to the paper's 2024-Q1
  risk–return comparison.

These figures contain aggregate paper results and no person-level participant
records.
